## E-Commerce UI Platform - CV Format

### Vị Trí: Frontend Developer

---

### 📝 Giới Thiệu
Phát triển nền tảng thương mại điện tử hoàn chỉnh gồm 2 ứng dụng Next.js độc lập: ứng dụng khách hàng với tìm kiếm, giỏ hàng, thanh toán VNPay; và admin dashboard quản lý sản phẩm, người dùng, đơn hàng với biểu đồ dữ liệu.

---

### 🛠️ Công Nghệ Sử Dụng
- **Frontend**: Next.js 16, React 19, TypeScript
- **Styling**: Tailwind CSS, Shadcn/ui, Radix UI
- **State & Form**: Zustand, React Hook Form, Zod
- **Data Visualization**: Recharts (Line, Bar, Area, Pie charts)
- **Payment**: VNPay API Integration
- **Icons & Components**: Lucide React, Day Picker
- **Tools**: ESLint, pnpm, Turbopack

---

### ✨ Tính Năng Chính

**Client (Khách hàng)**
- Duyệt sản phẩm, tìm kiếm, lọc theo danh mục/giá
- Giỏ hàng với localStorage persistence
- Chọn size, màu sắc sản phẩm
- Thanh toán qua VNPay
- Chọn địa chỉ giao hàng (tỉnh/thành phố)
- Responsive design (Mobile, Tablet, Desktop)

**Admin (Quản lý)**
- Dashboard với thống kê & biểu đồ
- CRUD sản phẩm, người dùng, đơn hàng, danh mục
- Form validation toàn bộ
- Data tables với pagination, sorting
- Dark/Light mode
- 15+ pages, 40+ components
